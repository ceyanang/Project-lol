# Working agreement

- Develop on the session's branch (`ccr-*` / `claude/*`) and push it. The **Auto-merge to main** workflow
  (`.github/workflows/auto-merge.yml`) tests, merges it into `main` and redeploys GitHub Pages — no PR or
  extra ask needed. Never push to `main` by hand.
- Follow `RULES.md`; keep `PLAN.md` in sync when changing `CONFIG` numbers.
